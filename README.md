# Nitron WidgetStudio

Конструктор кастомных виджетов для домашнего экрана: собирайте виджеты из слоёв,
тонко настраивайте каждый параметр и экспортируйте в PNG с альфа-каналом.

## Скачать APK

Готовая сборка — в разделе [Releases](https://github.com/nitronnnn/nitron-widget-studio/releases).
APK подписан отладочным ключом (самоподписанным): при установке Android покажет
стандартное предупреждение — это ожидаемо.

## Виджет на домашний экран (Android)

В редакторе: **Экспорт → На домашний экран**. Приложение сохранит дизайн,
после чего добавьте виджет стандартно: зажмите пустое место на рабочем столе →
«Виджеты» → **Nitron** → перетащите на экран.

- Прозрачный фон сохраняется — виден фон рабочего стола
- Часы, дата, обратный отсчёт и батарея (кольцо/полоса/процент) **живые** —
  нативный провайдер перерисовывает их каждую минуту
- **GIF и видео играют прямо в виджете**: foreground-сервис декодирует кадр
  12 раз в секунду и отдаёт его лаунчеру (RemoteViews не умеет анимацию сам)
- FX-анимации слоёв (пульс, вращение, парение, мигание) тоже работают в виджете
- Чтобы обновить дизайн — снова «Экспорт → На домашний экран»
- На Tecno/HiOS, Xiaomi, Realme: разрешите автозапуск и режим батареи
  «Без ограничений» для Nitron, иначе система остановит живой сервис

## Запуск

```bash
npm install        # или npx expo install --fix
npx expo start     # затем отсканируйте QR в Expo Go (Android/iOS)
```

Приложение полностью совместимо с **Expo Go** — нативная сборка не нужна.

## Возможности

### Слои (11 типов)
| Слой | Что умеет |
|---|---|
| Текст | шрифт, трекинг, капс, выравнивание, неоновое свечение |
| Фото | из галереи или URL, скругление, обводка, fit cover/contain/fill |
| **GIF** | анимированные гифки через expo-image, автоплей, те же настройки |
| **Видео** | expo-video, loop/mute/play, скругление, textureView-клиппинг |
| Фигура | квадрат, пилюля, круг, кольцо, треугольник, звезда, линия; заливка цветом или градиентом с углом |
| Часы | живые, 12/24ч, секунды, моно/сериф и др. шрифты, glow |
| Дата | шаблоны `D MMMM`, `DD.MM.YYYY` и свои токены |
| Батарея | живой заряд устройства: кольцо / полоса / текст |
| Прогресс | значение, градиентная заливка с углом, цвет трека |
| Отсчёт | обратный отсчёт до даты (дни:часы:мин:сек) |
| Иконка | 48 иконок Ionicons + произвольное имя, свечение |

### Альфа-канал
- Прозрачный фон холста — шахматная индикация в редакторе
- Каждый цвет с альфа-слайдером (HSVA-пикер + HEX `#RRGGBBAA`)
- Непрозрачность каждого слоя отдельно
- Экспорт PNG **сохраняет прозрачность** (react-native-view-shot)

### Редактор
- Жесты на холсте: перетаскивание, pinch-масштаб, поворот двумя пальцами
- Панели: Слои / Стиль / FX / Холст
- Undo/redo с умным слиянием серий (драг слайдера = один шаг истории)
- Порядок слоёв, видимость, замки, дублирование
- FX-анимации: пульс, свечение, парение, вращение, скольжение, мигание
- Смена размера виджета с автомасштабом всех слоёв

### 12 пресетов
Неоновые часы · Минимал (прозрачный) · GIF Booth · VHS Рекордер · Плеер ·
Кольцо батареи · Обратный отсчёт · Цитата · Крипто-тикер · Погода · Стрик · Фото-рамка

### Экспорт
- PNG 2×/3×/4× (до 1440×1520 px для большого виджета)
- В галерею или системный шаринг
- Хаптика, тёмная тема, автосохранение проектов (AsyncStorage + zustand)

## Стек

Expo SDK 58 · React Native 0.88 · Expo Router (typed routes) · zustand ·
Reanimated 4 · Gesture Handler 3 · expo-image / expo-video / expo-battery ·
react-native-svg · react-native-view-shot

## Структура

```
src/
  app/            # маршруты Expo Router: (tabs) + editor/[id]
  components/
    canvas/       # холст, шахматка альфы, фон
    layers/       # рендер слоёв + FX-анимации
    controls/     # слайдеры, HSVA-пикер, сегменты, тумблеры
    editor/       # панели инспектора
    cards/ ui/    # карточки, пустые состояния
  store/          # zustand: редактор (undo/redo), виджеты (persist), настройки
  data/           # фабрика слоёв, пресеты
  utils/          # цвет (HSVA↔HEX+alpha), время, экспорт, пикер медиа
  theme/          # палитра Nitron, типографика, платформенные шрифты
```
